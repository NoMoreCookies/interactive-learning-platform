# Interactive Learning Platform

An educational platform built with Next.js and TypeScript.

## Features

- Mathematics, Physics and Computer Science courses
- Course modules
- Lesson pages
- Notes
- Exercises
- Solutions
- Downloadable materials

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS

## Roadmap

- AWS Amplify
- Amazon S3
- Amazon Cognito
- User authentication
- Course progress
- Payment integration

## Local setup

npm install
npm run dev
